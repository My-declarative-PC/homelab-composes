# Beszel Agent

Compose-проект запускает только агент Beszel и Docker socket proxy. Его можно использовать на ноутбуке или другой машине, которую нужно подключить к хабу на mini-сервере.

## Настройка

1. В интерфейсе Beszel на mini-сервере добавьте систему и выберите подключение через WebSocket. Скопируйте выданные для агента `KEY` и `TOKEN`.
2. В корне репозитория скопируйте `available/beszel-agent/.env.example` в `available/beszel-agent/.env` и заполните `KEY` и `TOKEN`. Файл `.env` не попадает в Git.
3. На нужной машине включите и запустите проект:

   ```sh
   hctl enable beszel-agent
   hctl up beszel-agent
   ```

По умолчанию агент подключается к `https://beszel.big-black-duck.keenetic.link` и регистрируется как `laptop`. Значения можно переопределить в `.env` для другой машины или адреса хаба.

Агент использует исходящее WebSocket-соединение к хабу, а SSH-сервер агента отключён. Docker socket proxy предоставляет агенту доступ только к чтению данных о контейнерах и логов; его порт опубликован только на `127.0.0.1` и доступен агенту через host network.
